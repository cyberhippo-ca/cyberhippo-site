# cyberhippo.ca

Source for my portfolio site at [cyberhippo.ca](https://cyberhippo.ca).

- Plain HTML and CSS, no JavaScript, no frameworks, nothing to patch
- No external fonts, scripts or trackers: every file is served from this repo
- Hosted on Cloudflare Pages; every push to `main` redeploys the site
- Security headers are set in [`_headers`](_headers)
